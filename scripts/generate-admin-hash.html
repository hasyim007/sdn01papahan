🔐 Generator Password Admin (Offline, Tanpa Install Apa-apa)

File ini tidak perlu di-upload atau di-deploy — cukup buka langsung di browser komputer Anda (dobel klik file-nya). Semua proses hash password terjadi di browser Anda sendiri, tidak ada data yang dikirim ke internet. Hasilnya berupa perintah SQL yang tinggal Anda tempel (paste) ke D1 Console di Cloudflare Dashboard.

Catatan: Algoritma hash yang dipakai (PBKDF2-SHA256, 100.000 iterasi) persis sama dengan yang dipakai Worker saat memverifikasi login, jadi hasil dari halaman ini pasti kompatibel. Jangan bagikan password asli Anda ke siapa pun — hanya hasil SQL di bawah yang perlu ditempel ke Cloudflare.
